# 跨境服务商对标的可比组与受限结果发布资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

external-revenue在主承包方为外部合同总额减联盟内转包，合作方为实际转包服务收入。项目数按成员实际完成的服务合同解释，不能数申报行。
成员明细仅向自身开放，public结果所有人可见。相同接收者已经见过的结果不能通过撤回消除。
准确值只有同时满足minimum_contributors与max_share才可公开。贡献不足或过度集中的格只能公开至少minimum_interval_minor宽度的区间，与既有发布组合后任何同类不安全细格的可推导区间也须保留该宽度。准确值视为宽度零。
相容指标组合要采用共同可比企业和期间，不能把不同分母的人群拼成企业的综合结论。

## enterprises

联盟成员，不含真实企业信息。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 企业 |
| opened_on | str | 开业日 |
| market | str | 主要市场 |
| size | str | 规模层 |

## projects

联合项目及内部转包金额。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 项目 |
| lead | str | 主承包 |
| partner | str | 合作方 |
| total_minor | int | 合同外部总额 |
| internal_subcontract_minor | int | 内部转包额 |
| completed_on | str / null | 履约完成日，空为未完成 |

直接引用关系为lead → enterprises.id、partner → enterprises.id。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 申报 |
| enterprise | str | 企业 |
| project | str | 项目 |
| period | str | 月份 |
| service | str | 业务类别 |
| revenue_minor | int | 申报收入美分 |
| hours | float | 履约工时 |
| basis | str | 总包或转包口径 |
| version | int | 申报版本 |
| received_on | str | 接收日 |

直接引用关系为enterprise → enterprises.id、project → projects.id。

| id | str | 接收层级 |
